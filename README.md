# 計算機圖形學作業

中央大學計算機圖形學（Computer Graphics）作業，使用 Processing 4 實作。

| 作業 | 主題 | 說明 |
|---|---|---|
| Lab 1 | 2D 繪圖演算法 | [HW1/README.md](./HW1/README.md) |
| Lab 2 | 2D 幾何變換與多邊形裁剪 | [HW2/README.md](./HW2/README.md) |
| Lab 3 | 3D 渲染管線 | [HW3/README.md](./HW3/README.md) |
| Lab 4 | 光照與著色 | [HW4/README.md](./HW4/README.md) |

## 執行方式

1. 安裝 [Processing 4.x](https://processing.org/download)
2. 開啟要執行的作業主檔，例如 `HW1/HW1.pde`、`HW2/HW2.pde`、`HW3/HW3.pde`、`HW4/HW4.pde`
3. 按執行（Run）
